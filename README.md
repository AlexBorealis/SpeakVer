# SpeakVer 🎙️

**SpeakVer** — это система верификации и идентификации говорящего по голосу на базе архитектуры глубокого обучения ECAPA-TDNN (Emphasized Channel Attention, Propagation and Aggregation in TDNN Based Speaker Verification). Проект включает в себя полный цикл разработки: от загрузки и предобработки аудиоданных до обучения моделей и развертывания веб-интерфейса для тестирования.

---

## 🔥 Основные возможности
* **Архитектура ECAPA-TDNN:** Современное решение для извлечения устойчивых эмбеддингов голоса (Speaker Embeddings).
* **Конвейер данных:** Автоматический скрипт для скачивания и подготовки датасетов.
* **Удобное обучение:** Изолированные скрипты конфигурации, логирования и оценки метрик (EER, minDCF).
* **Веб-интерфейс (App):** Демо-приложение для интерактивной проверки голоса "свой/чужой" в реальном времени.

## 🛠️ Установка и настройка

### 1. Клонирование репозитория
```bash
git clone https://github.com
cd SpeakVer
```

### 2. Подготовка окружения
Рекомендуется использовать виртуальное окружение `venv` или `conda` (Python 3.10+):
```bash
python3 -m venv .venv
source .venv/bin/activate  # Для Linux/macOS
# или для Windows: .venv\Scripts\activate
```

### 3. Установка зависимостей
```bash
pip install --upgrade pip
pip install -r requirements.txt
```
*Примечание: Если проект использует системные библиотеки для работы со звуком (например, `libsndfile` или `ffmpeg`), убедитесь, что они установлены в вашей ОС.*

## 🚀 Использование проекта

### Этап 1: Подготовка данных
Для автоматической загрузки и структурирования обучающих аудиоматериалов запустите:
```bash
python download_data.py
```

### Этап 2: Обучение модели
Запустите цикл обучения нейросети. Конфигурация параметров сети настраивается внутри скрипта или через `pyproject.toml`:
```bash
python train.py
```

### Этап 3: Анализ результатов и метрики
Сгенерируйте отчет по результатам валидации (матрица ошибок, построение кривой DET/ROC, вычисление Equal Error Rate):
```bash
python report.py
```

### Этап 4: Запуск демонстрационного приложения
Запустите интерактивный интерфейс для верификации голоса:
```bash
python app.py
```
После запуска откройте локальный адрес в браузере (например, `http://localhost:8501` или указанный в консоли порт), чтобы загрузить аудиозапись и проверить совпадение спикера.

## 🧠 Используемая модель (ECAPA-TDNN)
В проекте используется архитектура **ECAPA-TDNN**, которая улучшает стандартный X-vector подход за счет:
1. Одномерных Squeeze-and-Excitation (SE) блоков для поканального внимания.
2. Многослойного агрегирования признаков (Multi-layer feature aggregation).
3. Суммирования контекста на основе стандартного отклонения и среднего значения (Attentive Statistics Pooling).
