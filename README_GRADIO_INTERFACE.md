# 🌐 Web Interface (Gradio)

После запуска приложения (скрипт [app.py](app.py))

```bash
python app.py
```

или

```bash
make run
```

в браузере станет доступен веб-интерфейс Gradio.

При первом открытии потребуется пройти авторизацию.

---

## Авторизация

Если в конфигурационном файле `.env` заданы пользователи

```text
USER1_LOGIN=user
USER1_PASSWORD=password
```

то перед входом необходимо ввести логин и пароль.

После успешной авторизации откроется основной интерфейс приложения.

---

## Вкладка Verification

Данная вкладка предназначена для сравнения двух аудиозаписей и определения, принадлежат ли они одному и тому же человеку.

## Experiment

Позволяет выбрать эксперимент.

Каждый эксперимент соответствует отдельной обученной модели, расположенной в каталоге

```text
runs/
```

После выбора эксперимента автоматически обновляется список доступных чекпоинтов.

---

## Checkpoint

Позволяет выбрать конкретный чекпоинт модели.

Доступны варианты:

- Default model — использовать предобученную модель SpeechBrain ECAPA-TDNN;
- best.pt;
- любой сохраненный чекпоинт обучения.

После выбора модель автоматически загружается в память.

---

## Model Status

Отображает информацию о текущей загруженной модели.

Например

```text
Using default SpeechBrain ECAPA-TDNN
```

или

```text
Loaded checkpoint:
/app/runs/experiment_01/weights/best.pt
```

---

## Cosine Similarity Threshold

Ползунок позволяет изменить порог принятия решения.

Диапазон:

```text
[-1 ; 1]
```

При увеличении порога система становится более строгой.

При уменьшении — более чувствительной.

Изменение значения не требует перезагрузки модели.

---

## Audio 1

Первый аудиофайл.

Можно загрузить:

- WAV
- FLAC
- MP3
- OGG

или любой другой формат, поддерживаемый Gradio и ffmpeg.

---

## Audio 2

Второй аудиофайл.

Не обязательно использовать записи из обучающего датасета.

Можно сравнивать любые реальные записи речи:

- записи с телефона;
- записи с диктофона;
- записи из интернета;
- записи из собственного датасета.

Главное условие — на записи должна присутствовать речь человека.

---

## Compare

После нажатия кнопки выполняются следующие действия:

1. аудио проходит предобработку;
2. вычисляются эмбеддинги обоих файлов;
3. рассчитывается cosine similarity;
4. сравнивается с выбранным порогом;
5. выводится результат.

---

## Prediction

Итоговое решение модели.

Возможные значения:

```text
SAME
```

или

```text
DIFFERENT
```

---

## Confidence

Уверенность модели.

Значение находится в диапазоне

```text
[0 ; 1]
```

Чем больше значение, тем выше уверенность модели в своем решении.

---

## Cosine Similarity

Фактическое косинусное сходство между двумя эмбеддингами.

Например

```text
0.81
```

или

```text
0.14
```

Именно это значение сравнивается с выбранным порогом.

---

## Вкладка Report

Позволяет автоматически оценить качество модели на тестовом датасете.

---

## Experiment

Выбор эксперимента.

Если выбрать

```text
Default model
```

будет использоваться предобученная SpeechBrain ECAPA-TDNN.

---

## Report directory name

Имя каталога, куда будет сохранен отчет.

Если оставить поле пустым,

будет автоматически создан каталог

```text
report_YYYYMMDD_HHMMSS
```

например

```text
report_20260721_194500
```

---

## Dataset Path

Путь до тестового датасета.

Например

```text
datasets/test
```

или

```text
/app/datasets/test
```

в Docker.

---

## Balance positive/negative pairs

Если включено,

количество положительных и отрицательных пар будет автоматически сбалансировано.

Это рекомендуется для корректного сравнения различных моделей.

Если выключено,

будут использоваться все возможные пары.

---

## Generate Report

Запускает скрипт [report.py](report.py)

```bash
python report.py
```

с выбранными параметрами.

Во время выполнения автоматически вычисляются метрики модели и строятся необходимые графики.

---

## Console Output

Отображает вывод программы в режиме реального времени.

Здесь можно увидеть:

- процесс обработки датасета;
- вычисление эмбеддингов;
- прогресс оценки;
- возможные ошибки;
- итоговые значения метрик.

---

## Типичный сценарий использования

1. Запустить приложение.

2. Авторизоваться.

3. Выбрать эксперимент.

4. Выбрать чекпоинт.

5. При необходимости изменить порог Cosine Similarity.

6. Загрузить два аудиофайла.

7. Нажать **Compare**.

8. Посмотреть:

- Prediction;
- Confidence;
- Cosine Similarity.

При необходимости перейти во вкладку **Report** и оценить качество модели на полном тестовом наборе данных.
